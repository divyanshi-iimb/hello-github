HOW TO PREVIEW:
1. Keep index.html and style.css in the same folder.
2. Open index.html in a web browser.

HOW TO PUBLISH WITH GITHUB PAGES:
1. Create or open the GitHub repository required by your assignment.
2. Upload index.html and style.css to the repository root.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose branch main and folder / (root), then Save.
6. Wait for the published Pages URL and test it.
